# My Personal Portfolio

Welcome to my personal portfolio! This website introduces me, showcases my skills and projects, and provides ways to connect with me.

## Features

* About Me section
* Education and academic record
* Technical skills and learning roadmap
* Projects showcase with GitHub links
* Contact information and social links

## Built With

* HTML5
* Git and GitHub
* Visual Studio Code

## Getting Started

To view the portfolio locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/Boni-777/my-portfolio.git
   ```

2. Open the project folder.

3. Open `index.html` in your web browser.
